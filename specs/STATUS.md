# STATUS — STAYA

- **Что это:** иммерсивный сайт организаторов вечеринок STAYA на Three.js — 6 пространств, скролл ведёт камеру. Статичный, без Next.js (`scripts/build.mjs` → `out/`).
- **Этап:** живой прототип на тестовом адресе https://staya.nikalimp.ru, версия v20 (06.11.2026). Выкладка — deploy-kit (`ssh-ftp`), PR агента сливаются сами (`pr.yml`).
- **Стандарт:** с 07.11.2026 — стартер для статичного сайта: `specs/`, `npm run check` (`scripts/check.mjs` = deploy-kit `check-static`), шрифты локально (Google Fonts убраны), `.htaccess` без редиректа на HTTPS.
- **Ждём:** домен клиента; после публикации на нём — Метрика, Вебмастер, Search Console (напоминание, стандарт §9.0).
- **Долг (предупреждения check):** нет JSON-LD, `sitemap.xml`, `llms.txt`; модель распознавания лица (`js/headtrack.js`) грузится с `storage.googleapis.com` — из РФ может не открыться, перенести в `vendor/`; PageSpeed мобильный — замер после выкладки (порог 90, стандарт §6.6).
