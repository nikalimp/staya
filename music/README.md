# Музыка STAYA

Положите сюда 6 треков в формате mp3. Имена файлов — ровно такие:

| Файл | Сцена |
|---|---|
| `01-aqua.mp3` | STAYA AQUA — аквапарк |
| `02-2k17.mp3` | STAYA 2K17 — клуб |
| `03-pool.mp3` | STAYA POOL — бассейн |
| `04-halloween.mp3` | HALLOWEEN — дворец |
| `05-phuket.mp3` | PHUKET — вилла |
| `06-office.mp3` | Офис команды |

Советы:
1. Длина 60–120 секунд. Трек играет по кругу, поэтому начало и конец должны стыковаться.
2. Битрейт 128 kbps, моно или стерео. Файл — до 2 МБ, чтобы быстро грузился на телефоне.
3. Если файла нет, сайт работает без звука в этой сцене.

Плеер сам делает кроссфейд между сценами. Первый трек грузится во время прелоадера.
