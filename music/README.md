# Музыка STAYA

Треки — пример от команды (DJ-эдиты Klën). На сайте играет не весь трек, а петля 20–40 с: 16 тактов самого плотного участка (припев или куплет).

Как устроен файл петли: 1 с хвоста петли + петля + 1 с её начала. Сайт крутит участок [1 с; 1 с + длина] через Web Audio (`loop` в SCENES, js/main.js), поэтому стык без щели.
Конец петли мягко (90 мс) переходит в звук, который в треке стоит перед началом фрагмента.

| Файл | Сцена | Трек | Фрагмент оригинала |
|---|---|---|---|
| `01-aqua.mp3` | AQUA | Klën & KIDDI — СВАГА (edit) | 17,3–55,3 с · 99 BPM |
| `02-2k17.mp3` | 2K17 | Klën — DIKO THRU THE 7TH NAPRIMER (2K17VIB33DIT) | 37,8–74,5 с · 103 BPM |
| `03-pool.mp3` | POOL | Klën — НА ЗАРЕ (edit) | 26,8–53,1 с · 144 BPM |
| `04-halloween.mp3` | Дворец | Klën — SHOCK ID (edit) | 44,0–76,9 с · 117 BPM |
| `05-phuket.mp3` | Вилла и офис | Klën & REDSQUARE — ЦЕЗАРЬ (edit) | 23,5–46,9 с · 162 BPM |

Вилла и офис играют один трек: при переходе в офис музыка не прерывается.
Заменить трек: собрать петлю скриптом выбора фрагмента (librosa: темп, такты, окно 8/16 тактов) и обновить `loop` в SCENES.
