# STAYA — иммерсивный сайт

Путешествие по 6 пространствам STAYA на Three.js. Скролл двигает камеру. Видео нет: вся сцена — 3D-геометрия в браузере.

## Как запустить

```bash
cd site
python3 -m http.server 8080
# открыть http://localhost:8080
```

Файл `index.html` нельзя открыть двойным кликом: модули грузятся только через сервер.

## Как устроено

```
Прелоадер: лого + кольцо с % → кольцо становится кнопкой Play (музыка + старт)
   ▼
AQUA ──в спину диджея (чёрный)──▶ 2K17: стена → лестница → толпа → луна-арт-объект
   ──склейка по кадру луны──▶ POOL: облёт настоящей луны (STAYA POOL) → бассейн → двери (чёрный)
   ──▶ ДВОРЕЦ: двери открываются → лестница → 2 этаж → фото виллы в телефоне
   ──склейка по фото──▶ ВИЛЛА: облёт → влёт в дом (чёрный) ──▶ ОФИС: кнопки связи
```

1. Каждая сцена — отдельный модуль в `js/scenes/`. Модуль грузится только когда нужен.
2. В памяти максимум 3 сцены: текущая и соседние. Остальные выгружаются.
3. На стыке сцен экран уходит в чёрный. Следующая сцена уже собрана, рывка нет.
4. Вся статичная геометрия сцены сливается в 6–10 мешей (`Builder` в `js/kit.js`). Одна сцена — 7–15 draw calls.
5. Кадр рисуется только когда камера сдвинулась. Сцена стоит — GPU отдыхает.
6. На экране нет интерфейса. Кнопки связи появляются только в финале (массив `LINKS` в `js/main.js`, пустой `href` — кнопка скрыта).
7. Стык сцен: `out: 'black'` — уход в чёрный, `out: 'cut'` — склейка по совпадающему кадру. Фото в телефоне во дворце — рендер первого кадра виллы в текстуру.

| Файл | Что внутри |
|---|---|
| `index.html` | разметка, стили, весь текст сайта |
| `js/main.js` | движок: скролл → камера, переходы, звук, прелоадер |
| `js/kit.js` | общие детали: люди, пальмы, фермы, пульты, вода, свечение |
| `js/scenes/*.js` | 6 сцен и пути камеры |
| `vendor/` | three.js r160 (локально, без зарубежного CDN) |
| `music/` | 6 треков — см. `music/README.md` |

## Отладка

`?debug` в адресе пишет в консоль время сборки сцен. В консоли:

```js
__staya.go(2.5)   // камера в середину сцены POOL (номер сцены + доля)
__staya.info()    // draw calls, треугольники, сцены в памяти
```

## Что сделать перед запуском

1. Положить 6 треков в `music/`.
2. Захостить шрифты Unbounded и Manrope локально (сейчас Google Fonts).
3. Отдавать сайт с хостинга в РФ или Yandex Object Storage, включить gzip/brotli для `.js`.
